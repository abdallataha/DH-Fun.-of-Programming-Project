Let’s find how many funding rounds do companies usually go through?

# After thinking for some time, this visualization needs 
# the calculation of the cumulative sum as the startup that funded for 18 
# rounds must have passed through the first, second till the 17th rounds
counts <- table(df_invest_cp$funding_rounds)
total_startups <- sum(counts)

# Calculate how many dropped out at each stage
dropped_out <- cumsum(counts)

# Subtracting the total startups number from each round acc. sum
# then I added the original counts (frequencies per funding round)
cum_rounds <- (total_startups - dropped_out) + counts

visual(type = "bar", x = round((cum_rounds / sum(!is.na(df_invest_cp$funding_rounds))) * 100, 1),
  title = "Percentage of companies per Funding Rounds", xlab = "Number of Rounds",
  ylab  = "Percentage of Companies (%)",
  col = "yellow")

Almost the third of the startups that got their first round, will go through a second one, but this gap narrowed after that from the third to the half. So, we can call the second round a statistical bottleneck for more rounds.

It is misleading to get conclusions from this graph or GDP graph directly, but knowing the population of these economic categories might reveal different conclusions.

# Calculate the mean funding for each category
mean_funding <- aggregate(funding_total_usd ~ income, data = df_invest_cp, 
                          FUN = mean)

# Get the population for each category (assuming it is a unique value per category)
pop_by_income <- aggregate(pop ~ income, 
                           data = unique(df_invest_cp[, c("country_code",
                                                          "income", "pop")]), 
                           FUN = sum)

# Merging both tables and divide
final_result <- merge(mean_funding, pop_by_income, by = "income")
final_result$fund_access <- round(final_result$funding_total_usd / final_result$pop, 4)
final_result <- final_result[order(final_result$fund_access, decreasing = TRUE), ]

{
  # Setting the layout (1 row, 2 columns)
  par(mfrow = c(1, 2), mgp = c(4, 1, 0), mar = c(10, 6, 4, 2))
  
  # Plotting the Population by Income
  visual(type = "bar", sort(round(tapply(final_result$pop,
                                         final_result$income, sum) / 
                                    100000000, 1), decreasing = TRUE), 
         ylab = "Total Population in 100M", 
         title = "Population per Income Group", las = 2)
  
  # Plotting the Funding Access
  visual(type = "bar", x = sort(tapply(final_result$fund_access, 
                           final_result$income, unique), 
                    decreasing = TRUE), 
         ylab = "Fund accessibility for startups", 
         title = "Startups Funding Access", las = 2)
  
  # Resetting layout to 1x1 so future plots aren't affected
  par(mfrow = c(1, 1))
}

Each additional round of funding significantly increases the chances of being acquired. This means that the continuous successful funding rounds is an indicator for successful exit (make sense).

While total funding is neutral, specifically having Venture funding has a positive, significant impact.

Being based in North America shows a strong positive correlation with acquisition.

Founded Year coefficient is highly negative. This means, as the year goes up (newer companies), the likelihood of having been acquired goes down. This makes sense also as older companies have had more time to exit and achieve higher revenues and higher potential for investors.

Surprisingly, higher seed funding has a tiny but statistically significant negative impact on the probability of acquisition in this model. This could imply that companies that highly depend on seed without moving to venture are less likely to exit. This makes sense as ventures are more involved in investors’ network and have a clear benefit from selling the company.
