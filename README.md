# DH-Fun.-of-Programming-Project
Fundamentals of Programming Project

The Goals:
Regarding the focus and the support of HPI on Enterpreneurship, this project aims to analyse the data, visualizing some of the important aspects behind it. Also, it aims to explain the possible reasons behind some visualizations that could be misunderstood. Through it, I should be able to predict the success (acquired vs closed) company.

The Dataset:
Information about startup companies and investment via Crunchbase. The investments series at a company level are given. The company status are given. The main dataset is 54294 rows * 39 columns. The demographics are merged from different databases (3letters, World Bank Indicators and other built-in libraries) to increase variables to +45 to find hidden untold story.
