# DH-Fun.-of-Programming-Project
Fundamentals of Programming Project

Regarding the focus and the support of HPI on Enterpreneurship, this project aims to find the factors that help company to be operating / closed / acquired stage.

The Dataset: Information about startup companies and investment via Crunchbase. The investments series at a company level are given. The company status are given. The main dataset is 54294 rows * 39 columns. The demographics will be merged from different databases to increase variables to 50 to find hidden untold story.
